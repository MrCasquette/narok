# ADR — Architecture Decision Records

Référence unique des décisions structurantes de ce repo. Chaque décision = un ADR numéroté, jamais
renuméroté. Amendé, jamais supprimé.

## Format

```
# ADR-000X — <titre>
Statut : accepté | proposé | remplacé par ADR-00YY   ·   Date
## Contexte            le problème / la contrainte
## Options envisagées
## Décision
## Conséquences        impacts, dette, suivis
```
